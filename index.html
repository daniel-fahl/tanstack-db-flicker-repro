awaitTxId resolves before persisted rows reach the collection

Todos synced through @tanstack/electric-db-collection, wrapped in persistedCollectionOptions with browser SQLite on OPFS. A fake in-page Electric server stands in for Postgres and Electric. The write handler sends the change, then awaits awaitTxId(txid).

Each run inserts a new todo and ticks it right away, like a user who adds an item and checks it off. It records every state the collection shows for that todo: missing → unticked → ticked. A flicker is any step back to an older state.
